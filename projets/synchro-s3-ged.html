Script de synchronisation des photos vers la GED

Un script Python qui recopie automatiquement les nouvelles photos web, déposées sur Amazon S3 par l'interface photos, dans la GED de l'ERP Infologic — avec le bon nom, sans doublon, et une trace de chaque envoi lisible dans Excel.

Contexte

Les photos ajoutées avec l'interface photos arrivent sur le site et sur Amazon S3, mais l'ERP de l'entreprise (Infologic) a sa propre GED, un partage réseau où chaque produit doit avoir une image nommée {code}.jpg. Sans outil, il fallait recopier et renommer ces fichiers à la main.

Fonctionnement

  1. Lister S3

    Le script parcourt toutes les photos web du bucket, page par page.

  2. Écarter ce qui est déjà fait

    Un fichier d'état (sync_state.json) mémorise chaque photo déjà traitée.

  3. Choisir la photo principale

    Les photos sont regroupées par code produit. Si plusieurs sont arrivées, c'est la première du dernier lot envoyé qui part (un lot = des envois espacés de moins de 60 s).

  4. Copier sans risque

    Téléchargement dans un fichier temporaire, puis remplacement atomique : la GED n'a jamais de fichier à moitié écrit, et la dernière photo remplace l'ancienne sans créer de doublon.

  5. Tracer

    Chaque action est écrite dans un journal, et chaque copie réelle ajoute une ligne au registre envois.csv, qui s'ouvre directement dans Excel.

Options

  • --dry-run : simulation, montre ce qui serait copié sans rien écrire.
  • --forcer : renvoie la dernière photo de tous les produits, pas seulement des nouveautés.
  • Lancement par double-clic ou par le Planificateur de tâches Windows.

Robustesse

  • Une erreur sur un fichier n'est pas mémorisée : il est simplement retenté au passage suivant.
  • Partage réseau inaccessible ou S3 illisible : message clair avec les pistes à vérifier (réseau, VPN, droits).
  • Si un fichier apparaît entre-temps dans la GED, la photo existante est conservée.
  • Le script installé est placé hors de OneDrive, pour ne jamais synchroniser les clés AWS dans le cloud.
