Contexte

Chercher un emploi dans plusieurs pays oblige à surveiller beaucoup de sites, à retrouver les mêmes offres plusieurs fois et à suivre ses candidatures à la main. J'ai voulu un outil qui fasse ce travail et m'aide à me concentrer sur les offres qui me correspondent vraiment.

Fonctionnement

  1. Collecte

    Recherche sur 4 API d'offres testées (Himalayas, Remotive, Jobicy, Arbeitnow), 3 autres prêtes à activer avec une clé gratuite, plus l'import CSV/JSON. Une source en panne n'arrête pas les autres.

  2. Normalisation

    Pays, langue, salaire converti en euros, liens nettoyés ; les postes de direction et les offres « USA only » sont écartés.

  3. Dédoublonnage

    Une offre est un doublon si elle a le même lien, la même empreinte (titre + entreprise + pays), ou une similarité d'au moins 90 % sur l'entreprise et le titre (RapidFuzz). Le doublon n'est pas recréé : son lien s'ajoute à l'offre existante.

  4. Score

    Score de 0 à 100, sans IA : compétences 45 %, expérience 25 %, métier 20 %, langue 10 %, bonus pour un pays prioritaire. Le détail du calcul est affiché sur chaque offre.

  5. Suivi

    Tableau de bord Flask bilingue FR/EN : filtres, et suivi de chaque candidature (à postuler → postulé → relancé → entretien → offre ou refus) avec historique.

La recherche se relance toutes les 6 heures, ou via deux tâches du Planificateur de tâches Windows (9 h et 18 h).

Sécurité & qualité

  • Clés d'API dans un fichier .env exclu de Git ; elles n'apparaissent jamais dans les messages d'erreur.
  • Jeton CSRF sur tous les formulaires.
  • Serveur accessible uniquement depuis la machine locale.
  • Aucun scraping des sites qui l'interdisent.
  • 78 tests automatisés avec pytest : sources, normalisation, doublons, score, filtres, base de données et interface web.
