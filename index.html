Alternance — Chazal Depuis janvier 2026

Gestion et enrichissement des photos produits

Contexte

De nombreux produits de l'enseigne « Les Halles by Chazal » n'avaient pas encore de photo, et la gestion des images demandait plusieurs manipulations manuelles réparties sur différents emplacements de fichiers.

Solution développée

Une application web interne permettant de rechercher des produits, de visualiser l'état de leurs photos, d'en ajouter (versions Web et HD), de filtrer les produits sans image, et de détecter automatiquement le code produit à partir du nom de fichier.

Ce que j'ai personnellement réalisé

Après avoir constaté qu'une personne ajoutait les photos une par une, j'ai développé une fonctionnalité d'import en masse : sélection de plusieurs fichiers, association automatique aux produits à partir des noms de fichiers, avec une validation humaine avant l'envoi final.

Vue.jsViteNode.js PythonAmazon S3

Projet interne — code non public. Détail complet disponible sur demande (rapport de projet).

Projet BTS SIO — SIO1 2025 — 2026 · Solo

CinéSIO

Contexte & objectif

Application web développée seul en 1re année de BTS SIO : un catalogue de films avec comptes utilisateurs et système de favoris.

Ce que j'ai réalisé

Catalogue de films (affiche, genre, durée, synopsis, pays), inscription/connexion avec gestion de session, système de favoris, ajout de films via formulaire validé côté serveur, upload d'avatar de profil.

Architecture & sécurité

Architecture en couches (pages / repositories / connexion PDO), mots de passe hachés (password_hash / password_verify), requêtes préparées, échappement systématique à l'affichage (htmlspecialchars), validation complète des formulaires.

Difficulté rencontrée

Faire cohabiter proprement les différentes technologies du projet (PHP, PDO, PostgreSQL, bonnes pratiques de sécurité) — un vrai apprentissage en cours de route.

PHPPDOPostgreSQL

Dépôt GitHub public — lien ajouté une fois la rotation du mot de passe de la base confirmée.
